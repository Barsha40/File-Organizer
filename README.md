
# File Organizer

## Description
A Python application that automatically organizes files
into folders based on their file extensions.

## Features
- Automatically detects file extensions
- Creates folders for different file types
- Moves files into appropriate folders
- Prevents overwriting existing files
- Handles files without extensions

## Technologies Used
- Python
- OS Module
- Shutil Module

## How to Run

1. Clone the repository.
2. Open the project folder.
3. Run:

   python organizer.py

4. Enter the folder path you want to organize.
